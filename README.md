# jamegam_gamejam
2d Godot game for the october game jam hosted by jame gam

I made a game called Dodge the Drop.

In this game, you are quite literally just a little guy—a tiny ladybug trying to survive in a giant human world. Scramble left and right across the table while dodging razor-sharp pushpins raining down onto you. How long can you survive before you get squashed?

Controls - Use your left and right arrow keys

Credits - All art was made by me using IbisPaint. Coding was done using Godot and VSCode.
